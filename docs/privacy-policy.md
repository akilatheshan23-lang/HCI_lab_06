# FitFlow privacy notice — coursework release 1.1.0

Effective date: 3 October 2026. Maintainer: Weerasingha V.P.K.P.A.T, student project IT23379442. Status: implementation-matched draft; support contact supplied by the project owner; public hosting to be verified after GitHub upload.

## Data and purpose

FitFlow stores the name, age, height, weight and focus you enter, plus self-selected journal targets, workout completion records, food entries, water counts, private community demo notes, likes, hidden samples, and weight check-ins. These records support the screens and journals you choose to use.

## Storage, sharing and processing

All records remain in local browser/WebView storage on the device. This release has no cloud account, server database, advertising, analytics, crash telemetry, health-platform integration or external AI provider. Android cloud backup is disabled. The Android app has no INTERNET permission and blocks external navigation except opening the exact project privacy-policy URL in the system browser. The desktop preview uses a loopback-only server. Local JSON export lets you copy data; any subsequent sharing of that file is your choice.

“Daily Flow” selects one routine using the chosen goal. It is a rule-based local suggestion, not generative AI or clinical assessment. Community entries are sample content or your private notes, not posts visible to other people.

## Choices, retention and deletion

Edit your profile in the app. Delete meal entries and personal notes individually. Export a JSON copy from Profile. Delete all local data from Profile after reviewing the confirmation. Records otherwise remain until local app/browser storage is cleared or the app is uninstalled. No server copy exists in this release.

## Security and limitations

App data is kept in the device's application/browser storage, but FitFlow does not add its own database encryption. Protect your device and exported files. The application is for adult coursework testing; do not store sensitive medical records. It does not diagnose, treat, or provide emergency assistance.

## Rights and deployment review

Local editing/export/deletion controls provide practical data control. This document does not establish GDPR or HIPAA compliance. Their applicability and any additional obligations must be assessed for the actual organization, users, and deployment before public release. If cloud AI, analytics, authentication, or real social features are added, this notice and store disclosures must be revised before enabling them.
